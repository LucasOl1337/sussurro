# Fontes do Sussurro

- **Figtree** (Regular, Medium, SemiBold): interface. © The Figtree Project Authors, https://github.com/erikdkennedy/figtree
- **EB Garamond** (Regular): números das estatísticas e títulos. © The EB Garamond Project Authors, https://github.com/octaviopardo/EBGaramond12

As duas são distribuídas sob a SIL Open Font License 1.1 (`OFL-*.txt`). O app registra
estas fontes ao abrir (Linux: `~/.local/share/fonts/sussurro`; Windows: só para o processo).
